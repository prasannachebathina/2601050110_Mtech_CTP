Student Attendance Management System
📌 Project Description
This is a simple Python-based Student Attendance Management System. The program accepts student attendance details, calculates the attendance percentage, determines eligibility based on a 75% attendance threshold, and displays a complete class summary.

✨ Features
Enter details for multiple students
Store student name, total working classes, and attended classes
Calculate attendance percentage automatically
Display Eligible status for attendance of 75% or above
Display Shortage status for attendance below 75%

Find the highest attendance
Find the lowest attendance
Calculate the class average attendance

🛠️ Technologies Used

Python 3

Jupyter Notebook

▶️ How to Run

Open the Student_Attendance_Management.ipynb file in Jupyter Notebook.

Run the code cell.

Enter the number of students.

Enter the required attendance details for each student.

View the attendance report and class summary.

🧮 Attendance Formula

Attendance Percentage = (Classes Attended / Total Working Classes) × 100
